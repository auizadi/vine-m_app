# VineCare : Aplikasi deteksi penyakit daun tanaman angur

Aplikasi ini digunakan untuk mendeteksi penyakit daun tanaman anggur. Teknologi *computer vision* digunakan pada pengembangan aplikasi berbasis mobile ini. Model YOLOv11 digunakan untuk melatih dataset untuk mengenali jenis-jenis penyakit daun tanaman anggur.
